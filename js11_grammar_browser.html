JavaScript 1.1 Specification

Netscape Navigator 3.0 (1996) / ECMA-262 Edition 1

JavaScript 1.1 was introduced with Netscape Navigator 3.0 in 1996, laying the foundation for the first ECMA-262 standard (ECMAScript 1).

Key Features of JS 1.1 Grammar:

  • Array and Object literals (`[...]` and `{...}`)
  • Operators: `delete`, `typeof`, `void`, bitwise shift operators
  • Constructor functions and `new` operator syntax
  • `for...in` iteration loops

Note: Early JS 1.1 lacked features added in later specifications like `let`/`const`, arrow functions, `try/catch`, async/await, or class declarations.
